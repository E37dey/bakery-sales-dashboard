# Working practice

1. Commit and push automatically after every change, without asking first (standing instruction from the owner, 2026-11-02). Use plain `git` for this.
2. Keep README.md up to date: the dashboard description and the feature list change in the same commit as the feature.

Extra rules for this repo:

- Every `gh` command is printed before it runs.
- Auto commit and push covers this repo only. Anything outside it (making the repo public, enabling GitHub Pages, deleting or force-pushing) still needs an explicit yes.
